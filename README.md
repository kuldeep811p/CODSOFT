# CodSoft Artificial Intelligence Internship

Welcome to my repository for the **CodSoft Artificial Intelligence Internship**! This repository serves as a portfolio of the projects and tasks I completed during the internship program, showcasing practical applications of Machine Learning, Deep Learning, and AI concepts.


## 🚀 Projects Overview
Here is the list of tasks assigned and completed during the internship:

### 🔹 Task 1: Rule-Based Chatbot with Memory & Mood Detection
* **Objective:** Built an advanced rule-based chatbot that remembers user information (name, age, hobbies), detects mood from conversation, and provides features like math solving, dictionary definitions, number guessing game, and chat history export.
* **Tech Stack:** Python, Regex, JSON, Datetime
* **Key Learnings:** Pattern matching with regex, conversation state management, mood detection algorithms, safe mathematical expression evaluation, and session data persistence.

### 🔹 Task 2: Unbeatable Tic-Tac-Toe AI with Minimax Algorithm
* **Objective:** Developed an AI opponent for Tic-Tac-Toe with 3 difficulty levels (Easy/Medium/Hard), where Hard mode uses the Minimax algorithm to play perfectly and never lose.
* **Tech Stack:** Python, Minimax Algorithm, Alpha-Beta Pruning
* **Key Learnings:** Game tree traversal, optimal move calculation, alpha-beta pruning for efficiency, difficulty scaling with randomness, persistent score tracking, and move replay functionality.

### 🔹 Task 3: Image Captioning using Transformer Model (GIT)
* **Objective:** Created an AI system that generates natural language descriptions for images, supporting single images, batch processing of entire folders, and multiple caption variations with adjustable length (short/medium/detailed).
* **Tech Stack:** Python, Transformers (Hugging Face), PyTorch, PIL, Microsoft GIT-base-COCO Model
* **Key Learnings:** Working with pre-trained vision-language models, beam search for diverse caption generation, GPU/CPU optimization, batch processing with progress bars, and handling both local files and URLs.
